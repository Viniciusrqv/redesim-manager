- CSS inline com `/* ===== Title ===== */` quebra o `<style>`
- **Solução:** CSS sempre em `static/style.css`, lido via Python e injetado

### JS-tool limita output a ~1700 chars
- Pra processar muitos dados via Chrome MCP, usar `localStorage.setItem(...)` no navegador e pegar em pedaços menores

### Sandbox sem DNS pro Supabase
- Pra rodar scripts que tocam o banco, usar GitHub Actions workflow `popular_bases.yml`
- Botão "Run workflow" no painel do GitHub Actions

### Sandbox sem acesso a api.gestta.com.br via curl
